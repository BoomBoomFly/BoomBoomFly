## 环境与故障定位

- Jetson，L4T R36.5.2，内核 `5.15.199-tegra`，ROS 2 Humble。
- RealSense SDK 2.58.1、ROS wrapper 4.58.1；相机固件 5.15.1。
- 9 月 3 日 ROS 日志反复出现 `Depth stream start failure`。
- 本次原生后端测试中，640×480@30 的深度、彩色各自连续取得 60 帧，未复现上述错误。
- 原生后端同时报告 `No HID info provided, IMU is disabled`，联合请求图像与 IMU 时
  报 `Couldn't resolve requests`。`/proc/config.gz` 确认 `CONFIG_HID_SENSOR_HUB` 未启用。
- 此台相机的 IMU 为 BMI085：加速度计支持 100/200/400 Hz，陀螺仪支持 200/400 Hz；
  不能套用其他 D435i 的 63 Hz 加速度配置。

## 修复方式

在 Jetson 的 RealSense 构建中使用 SDK 的用户态 RSUSB 后端。此选择不要求修改内核或相机固件。
后端说明见 [SDK 的 Jetson 安装文档](https://github.com/realsenseai/librealsense/blob/bf2778061d5dd29776e9aca8765f75852671760b/doc/installation_jetson.md)。

从工作区根目录执行：

```bash
./Scripts/workspace/build.sh realsense2_camera
source /opt/ros/humble/setup.bash
source px4/px4_ws/install/setup.bash
ros2 launch realsense2_camera rs_launch.py \
  camera_name:=D435i \
  depth_module.depth_profile:=640x480x30 \
  rgb_camera.color_profile:=640x480x30 \
  enable_depth:=true enable_color:=true \
  enable_accel:=true enable_gyro:=true \
  accel_fps:=100 gyro_fps:=200 unite_imu_method:=2
```

预期话题为 `/camera/D435i/depth/image_rect_raw`、`color/image_raw`、`accel/sample`、
`gyro/sample` 和 `imu`（后四者使用相同 `/camera/D435i/` 前缀）。验证时必须检查实际消息，
不能只以 `RealSense Node Is Up!` 判断成功。
