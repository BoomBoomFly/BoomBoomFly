# 安全清单

## 每次测试前

- [ ] 螺旋桨状态与本次授权一致；默认拆桨。
- [ ] QGC、遥控器、Kill 和人工接管可用。
- [ ] 电池、电机、旋向和传感器状态正常。
- [ ] 室内围栏、速度和高度限制已设置。
- [ ] T265 local position 有效，方向、尺度和漂移已确认。
- [ ] DDS Agent 唯一，Domain 正确，`/fmu/in/*` 无重复 writer。
- [ ] Offboard setpoint 已连续预流至少 1 s。
- [ ] PX4 日志可用，测试人员和紧急停止口令已确认。

## G4 拆桨失效场景

按五类分别测试，每类保留独立日志：

| 类别 | 场景 |
| --- | --- |
| 通信 | RC 丢失、Agent 退出 |
| 控制 | Offboard 丢失、ACK 拒绝或超时 |
| 定位 | T265 冻结或断流 |
| 紧急 | Kill |
| 保护 | 低电、围栏 |

统一通过条件：

- 任务立即停止推进；
- 不自动重新进入 Offboard；
- PX4 进入预期安全动作；
- 能人工接管或安全 Land/停止；
- 状态、ACK、时间点和 PX4 日志可复核。

## 装桨准入

只有 G0–G4 全 PASS、参数再次审计、首次飞行场地清空并取得当次明确授权后，才可执行
0.5 m 低速短时测试。任一条件变化都需重新检查，不沿用上一次授权。
