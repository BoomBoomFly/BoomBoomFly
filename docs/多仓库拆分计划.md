repo 客户端先在全新目录获取，不直接转换现有开发目录。

## 验证

- 四个 UGV 包从独立临时目录构建通过。
- 主机 UDP 闭环、导航几何、任务控制测试合计 6 项通过，无跳过。
- 脚本在临时仓库和本地 bare 远程通过提交推送、克隆、快进和范围保护测试。
- 使用官方 repo 工具在全新临时目录执行 init/sync，12 个项目提交与本地源仓库一致。
- 原有源文件和硬件 evidence 内容经 SHA-256 对照保留。

上述结果是构建、主机仿真和本地仓库获取验证，不是实际 GitHub 新仓库获取或车辆硬件验收。
完整任务仿真仍缺少 `vision_bridge`。
