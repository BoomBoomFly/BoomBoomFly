# BoomBoomFly 第一阶段验证计划

本文件只记录当前范围、证据和待验证项。架构与不变量见[统一技术路线](BoomBoomFly_统一技术路线.md)，
当前交接见[handoff.md](handoff.md)。

## 已冻结的范围

| 项目 | 选择 |
|---|---|
| 控制接口 | `px4_msgs + uXRCE-DDS + Offboard`；不正式依赖 Custom Mode/ModeExecutor。 |
| 控制所有权 | 一个 `offboard_mission_node` 独占三个生产 `/fmu/in/*` 控制话题。 |
| `common` | C99 core 加 ROS 2 适配；core 可被 STM32 工程直接纳入。 |
| 视觉注入 | 单一路径 `nav_msgs/Odometry → VehicleOdometry → DDS → PX4 EKF2`。 |
| 取消 | `/offboard/cancel_mission` 服务仅在 `HOVER` 接受，随后本地返航并 Land。 |
| 安全权限 | 程序不 ARM、DISARM 或 Kill；只有 RC 解锁沿可启动任务。 |

## SITL 验证矩阵

| 项目 | 状态 | 证据边界 |
|---|---|---|
| DDS/readiness | 已通过 | `VehicleStatus_v1`、本地定位和 Timesync 的 QoS 与样本已实测。 |
| 正常闭环 | 已通过 | RC 解锁、Offboard、起飞、60 s 悬停、返回、Land 与解除解锁已完成。 |
| 外部 ARM | 已通过 | `COMMAND_EXTERNAL` 不触发任务。 |
| 人工接管与节点退出 | 已通过 | 切出 Offboard 或 mission 退出后，PX4 收口，mission 不重抢控制权。 |
| Land 新样本保护 | 已通过 | Land 请求前缓存的 `landed = true` 不会结束 `WAIT_LANDED`。 |
| 合成视觉 EKF2 融合 | 已通过 | 仅静止合成输入、仅未解锁 SITL；不代表真实 VIO。 |
| mission 本地位置输出断流 | 已通过 | mission 约 238 ms 后请求 Land，命令通路保持可用。 |
| 状态输入断流 | 部分通过 | Agent 暂停同时切断命令通路，不能证明 mission Land 到达 PX4。 |
| Offboard ACK timeout/拒绝 | 已通过（注入） | 覆盖 mission 分支，不代表 PX4 原生拒绝。 |
| PX4 原生模式拒绝 | 部分通过 | 已见不支持 AUTO 子模式的拒绝；不是 mission 自身请求。 |
| ACK 接受但 nav state 未切换 | 未复现 | 一次真实握手在约 12 ms 后进入 Offboard；仍缺 timeout 证据。 |
| PX4 Offboard-loss/failsafe | 已通过 | 仅断 Offboard 心跳后，PX4 failsafe，mission 不重抢权。 |
| 返航取消 | 已通过 | HOVER 中服务成功；`RETURN_HOME` 的 `CANCELLED` reason、Land ACK、新 `landed = true` 样本和解除解锁均已由 SITL rosbag 记录。 |
| time-jump/reconnect | 部分通过 | 受控 Agent 重连后 DDS `TimesyncStatus` 恢复，样本间隔约 1.004–1.008 s；自然 time-jump 根因仍未知。 |

## 下一轮 SITL

1. 为 mission 自身原生 Offboard 拒绝和 state-timeout 分别采集匹配 ACK、原始 `nav_state`、mission
   state/event 与 ulog。
2. 为自然 time-jump 连续记录 `TimesyncStatus` 的 source/remote timestamp、DDS session、PX4/Agent PID 和样本间隔，
   再与已完成的受控 Agent 重连样本比较。

## 实机前停止条件

真实 VIO frame/外参/时间、Foxy/Jetson 构建、无桨 Kill 与人工接管、定位中断与 Offboard-loss 演练、
以及现场操作员逐项批准均须通过。实机只按[第一阶段实机门禁清单](第一阶段实机门禁清单.md)执行。
