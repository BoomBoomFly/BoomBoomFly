# MCU 板级工程（`boards/`）

本目录按“芯片或板卡 + 用途”组织具体可编译、可烧录的板级固件工程，命名约定为 `<芯片或板卡>_<用途>/`（例如 `stm32f407_car_chassis/`）。

## 推荐工程内部分层

```text
<芯片或板卡>_<用途>/
├── README.md          # 芯片型号、引脚分配、通信协议/波特率、编译与烧录说明
├── app/               # 业务主逻辑（控制循环、任务状态机、安全保护、指令分发）
├── bsp/               # 板级硬件适配层（封装具体芯片 HAL/引脚，供 app/ 和 libs/ 调用）
├── vendor/            # 厂商生成代码（如 CubeMX Core/、Drivers/、启动文件与链接脚本）
└── ...                # 工程构建入口（如 CMakeLists.txt / *.ioc / *.uvprojx / platformio.ini）
```

## 约束

- 厂商工具生成的代码尽量集中放在 `vendor/`，避免与 `app/` 业务逻辑混杂。
- 芯片无关的协议、算法与器件驱动优先下沉到 `../libs/`，由各板级工程通过 `bsp/` 适配调用。
